# Praat歌詞合成の歯擦音抑制

歌唱用整形が改善した後にも残った、さ行・「ち」「つ」の高域の刺さりを抑えるための処理。追加の依存パッケージやシステム導入は不要。

## 処理と設定

- 対象は目標音素 `s/sh/ts/ch/z/j`。母音、促音の閉鎖区間、通常の `t/k` は対象にしない。
- 音素の音量調整を終えた後、高域のエネルギー比が高いフレームだけ減衰する。抑制後の音量再正規化はしない。
- 4〜6 kHzの滑らかな移行帯を使い、6 kHz以上で指定した最大減衰量になる。高域比15%以下では減衰指令なし、55%以上で最大。1024サンプルのHann窓、256サンプル間隔、アタック2ms・リリース25ms。
- 音素の選択・F0・伸縮・配置は変更しない。`plan.json` の各transformへ `deess_db` を保存（計画バージョン3）。音素ごとの処理が隣の母音に及ばないよう、抑制する音素は個別に合成する。

| 指定 | 動作 |
| --- | --- |
| 省略、sustain | 最大6 dB |
| `--lyrics-deess 9` | 強め、最大9 dB |
| `--lyrics-deess 0` | 無効、追加前の処理 |
| 省略、preserve | 無効、原音保持を優先 |

指定範囲は0〜12 dB。source経路のみで使用し、WORLD経路には適用しない。無効時はFFT処理を通さない。全体のトラックゲイン・EQ・最終ピーク調整は既存どおり。

## 同じ素材による比較

入力は `work/iwashi_lyrics_sample/praat_sustain/plan.json`。再選択せず、857音の保存済み計画を再生し、対象46音だけに歯擦音抑制を追加した。

出力先: `work/iwashi_lyrics_sample/praat_deess/`

- `mix-before-18-30.wav` / `mix-6db-18-30.wav` / `mix-9db-18-30.wav`: 18〜30秒の伴奏付き比較。
- `vocals-before-18-30.wav` / `vocals-6db-18-30.wav` / `vocals-9db-18-30.wav`: 同区間の歌声のみ。
- `mix.wav` / `vocals.wav`: 最大6 dB抑制の全曲、約171秒。
- `plan.json` / `comparison.json`: 加工計画と測定値。

Praatの再合成には繰り返しでサンプル値が変わる区間がある（同じ計画を2回合成して確認）。そのため、今回の「抑制なし」も保存済み計画から再合成した音声。各音素を一度だけ合成し、その波形を全比較で共有した。元の出力との完全な波形一致は主張しない。

元の無加工コピー子音からマスター倍率1.23930を推定し、コピー区間の再現誤差は約0.0000306（PCM16約1量子化幅）。元の伴奏とこの倍率を全比較で共通使用した。比較ごとのピーク正規化・伴奏の自動バランス再計算はしていない。通常のCLI再実行では既存の自動バランスと最終ピーク調整も再計算される。

対象音の6 kHz以上のエネルギー変化の中央値は6 dB設定で-5.96 dB、9 dB設定で-8.93 dB。全曲ミックスのピークは約0.8913、全サンプルが有限値、長さは変更なし。聞き取りや自然さの優劣は試聴で判断する。

再現コマンド（リポジトリルートで実行）:

```powershell
uv run --no-sync --offline --cache-dir .uv-cache python docs/research/compare_praat_deess.py
```

テストでは高域の減衰と低域の保持、無効時の一致、短い音・無音、音量調整による抑制の打ち消し防止、音素結合の制限、CLIの既定値・0・9 dBとWORLD非適用を確認する。

全130テスト、Ruff、`git diff --check`を通過。測定値は[比較結果](research/praat-deess-results.json)にも保存。

限界: 音素ラベルに基づくため、母音に混入した歯擦音や通常の破裂音の強さは別途調整が必要。強く抑えすぎると「す」「つ」などが曖昧になるため、まず6 dBと9 dBを比較する。
