# 無声子音の回帰調査と修正

続報: [Praat経路へ母音持続・音量調整・接続の重なりを追加](praat-singing-processing.md)。以下はその追加前の調査と修正の記録。

2026-09-20。ユーザー報告: 新しいPraat経路で自然さが失われ、特に18〜30秒の「つ」「す」が強く、ぶつぶつ切れて聞こえる。
対象は`work/iwashi_lyrics_sample/praat/`の`plan.json`・`vocals.wav`・`render.log`。
ログから、`work/corpus_sample.sqlite`、`target/iwashi_madgen.ust`とMIDI伴奏を使用した実出力であることを確認した。

## 確認した問題

最初の検証は母音が中心であり、子音の品質確認が不足していた。サンプル数と母音F0の一致は、子音を含む自然さの保証にはならなかった。

| 問題 | コード・実出力の根拠 |
| --- | --- |
| 無声子音にF0が検出されると楽譜音高へ移調 | 修正前の`make_plan`は全音素の有声フレームを補正対象としていた。実曲全体で`sh`13個中9個、`ch`7個中6個、`t`52個中39個が補正された。検出F0だけでは、本来有声の子音か、母音混入・誤推定かを区別できない |
| 数サンプルの長さ差でもPraat経由 | `identity`が厳密一致のみで、それ以外は非母音も全体伸縮。`s`12個と`ts`10個がすべて再合成されていた。典型的な倍率は0.99887と0.99962で、実質的に同長でも摩擦音を作り直していた |
| 別録音の音量関係を調整しない | 音素ごとの固定音量を除去した一方、異なる素材を接ぐ際の突出を扱っていなかった。21.333秒の`ch`は後続母音冒頭より約4.2 dB大きく、25.778秒の`ts`は約-3.8 dBだった |
| 接続の両側に5msフェード | 元録音で連続しない素材を独立グループとし、子音末尾と母音冒頭をそれぞれ5msフェード。接続前後の10msを減衰させていた |

音量値は、子音区間全体と後続母音の先頭最大120msのRMS差であり、聴感の強さそのものではない。
18.889秒の`s`は同じ測定では母音より18.5 dB小さかったため、「すべてのsが大音量になった」とは断定しない。摩擦音の質感・短い境界・素材の選び方を分けて扱う。

## 修正内容

[source_synth.py](../src/madgen/source_synth.py)、[match.py](../src/madgen/match.py)を変更した。

1. 音素表の無声子音（`s, sh, ch, ts, t, k, p, h, f`等）は`preserve_waveform=True`にし、検出F0があってもピッチ補正・PSOLA伸縮をしない。長い素材は枠内へ切り、短い素材は母音開始へ合わせて右寄せする。切断サンプル数と実出力開始を計画に保存する。
2. 無声子音を、加工する母音と同じPraatジョブへ戻さない。原音コピー同士で元録音上も連続している場合はまとめられる。
3. 無声子音の素材選択では、楽譜音程への近さの代わりに実使用範囲の有声率を評価する（最大8の加算）。補正を止めるだけでは、母音が混じった候補を選びやすくなる問題もあった。長い素材を切り捨てる割合もコストへ追加した。
4. 別素材の無声子音→母音接続で、子音の予測RMSが母音の-6 dBを超える場合のみ減衰する。最大減衰は12 dB、増幅はしない。予測エネルギーは実波形を計画の時間対応で重み付けして算出する。元録音の隣接区間の音量関係は変更しない。
5. この音量調整は選択後の接続計画として確定し、`gain`に保存してから合成する。選択の局所コストとは別の最終調整であり、合成中に推測して適用するものではない。
6. 出力上で接する独立グループのフェードを片側1msへ短縮。休符に面する外縁は5msを維持し、音符の外へ音声を延ばさない。

固定の音素RMSへ一律正規化する処理は戻していない。接続ゲインは波形全体へ一つの倍率を掛けるため、破裂・摩擦音内部の強弱は維持する。
上記の6 dB・12 dB・1msは今回の修正値であり、全話者・曲で最適とする検証はしていない。

## 再現と比較音声

[検証スクリプト](research/check_consonant_regression.py)は既存DBを読み取り専用で開き、77ユニットの短い範囲だけを処理する。既存出力を上書きしない。

```powershell
uv run --no-sync --offline --cache-dir .uv-cache python docs/research/check_consonant_regression.py --previous work/iwashi_lyrics_sample/praat --db work/corpus_sample.sqlite
```

出力先: `work/consonant-regression-18-30/`

- `before.wav`: ユーザーの実出力`vocals.wav`の18〜30秒。
- `after-fixed-material.wav`: 同じ素材選択で、上記の加工・音量・接続修正だけを適用。
- `after-reselected.wav`: 修正後の選択処理でも素材を選び直した音声。
- `comparison.json`: 修正前、素材固定、再選択の全計画・ゲイン・素材ID。

3ファイルとも12秒のボーカルのみ。変更していない母音の内部から元のマスター倍率を推定し、修正版の両方に同じ倍率を適用する。比較ごとに別々のピーク正規化はしない。比較スクリプトは既定のsource設定を前提とし、全曲のViterbi経路を再現するものではない。

素材固定の比較では、21.333秒の子音/母音RMS差は約+4.2 dBから-4.1 dB、25.778秒は約-3.8 dBから-7.3 dBになった。計画上の閾値と実際の冒頭120msの値が一致しないのは、前者が母音全体の予測エネルギーで、後者が加工後の冒頭区間だからである。
音質改善の最終判定は聴取を要する。数字だけで「自然さが戻った」とは判定しない。

## 自動検証と残る制約

修正後は全112テスト、Ruff、`git diff --check`を通過。比較範囲の無声子音20個は、素材固定・再選択の両方でピッチ補正0個、原波形コピー20個になった。3つの比較WAVは各12秒、有限値のみでピーク1.0未満を確認した。

追加テストは[tests/test_source_synth.py](../tests/test_source_synth.py)。無声子音6種のF0混入、数サンプル差での原波形コピー、短い子音の母音前への配置、共同再合成の禁止、突出時だけの減衰、原音隣接時のゲイン不変、1ms接続フェード、無声候補の選択を検証する。

- USTの子音は依然として原則60ms（短音符では最大40%）。素材に応じた可変長CV設計は未実装。
- `っ`単独は従来どおり無音扱い。今回確認した`iwashi_madgen.ust`には`っ`・`ッ`表記はなく、この区間について促音トークン処理の回帰とは確認できなかった。
- 異なる録音同士の自然な音韻遷移そのものを生成する機能、USTの子音先行・ピッチ曲線は未実装。
- 高音や不安定な母音F0、母音素材の静かな出口を含む問題は、無声子音の今回の修正だけで解消するとは限らない。

## 追加確認: 子音修正後もほぼ改善しなかったとの報告

ユーザーの聴取では上記修正による改善はほぼなかった。無声子音の再合成という実装上の問題を修正したことと、聴感上の主因を解消したことは区別する。現段階で本修正を自然さの改善成功とは扱わない。

元のWORLD出力と最初のPraat出力の18〜30秒を追加比較した。双方のログで、入力コマンド（出力先を除く）、コーパス件数、楽譜、857個の歌詞ユニットが一致することを確認した。独立したレンダリング間の比較であり、コーパス内容ハッシュを保存した厳密な対照実験ではない。

| 比較項目 | 旧WORLD出力 | 最初のPraat出力 |
| --- | --- | --- |
| 母音・撥音42ユニットのRMS、10–90パーセンタイル | 約-18.0〜-17.8 dBFS | 約-31.0〜-20.0 dBFS |
| 子音30ユニットのRMS、10–90パーセンタイル | 約-24.7〜-23.0 dBFS | 約-35.2〜-22.5 dBFS |
| 素材ID | 比較基準 | 対象の母音42個・子音30個すべてで旧出力と異なる |

出力に適用されたマスター倍率は異なるので、絶対音量差だけでは評価しない。一方、母音の音量のばらつきが大きくなったことは、一定のマスター倍率では説明できない。

旧実装には接続を均す処理が複数あった。

- 母音の大きく有声なコアを選び、減衰・息・無音を外し、ノート長を安定して鳴らす。
- スペクトルエネルギーを均し、無声F0を補い、低域の非周期性を抑える。
- 音素のRMSを一定にし、子音の目標を母音より6 dB低くする。
- 音符より最大20ms長い音声の末尾をフェードし、次の音符と重ねる。新方式の接続フェード短縮だけでは、この重なりは戻らない。

新方式はこれらを一度に外し、素材選択まで変更した。そのため、原録音の減衰や強弱を残した結果が、別素材をつないだ歌全体では弱い母音・音量段差・途切れとして現れた可能性がある。破裂・摩擦音そのものの問題だけでなく、受ける母音と接続処理を調べる必要がある。

次の検証は旧WORLD出力を基準に、旧選択素材を固定し、(1)母音持続・音量、(2)接続の重なり、(3)加工エンジン、(4)素材選択を分ける。共通の区間/F0/伸縮計画という設計と、波形・音量・探索方法の変更は独立して検証できる。今回は追加の音質パラメータ変更は行わず、原因の切り分けを優先する。
